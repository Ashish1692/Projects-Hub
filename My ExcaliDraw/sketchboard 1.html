Sketchboard

A hand-drawn whiteboard in a single HTML file

Sketchboard is an unofficial clone built as a tribute to Excalidraw, the open-source virtual whiteboard for sketching hand-drawn-like diagrams. Its look and feel, keyboard shortcuts, element model and .excalidraw / .excalidrawlib file formats follow Excalidraw so your drawings can move between the two.

Huge thanks to the Excalidraw team and contributors. If you like this, please use and support the original: github.com/excalidraw/excalidraw.
