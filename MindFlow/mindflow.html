Arrange

Select one node to arrange its branch, select several to arrange their combined branches, or clear the selection to arrange the whole map. The Inspector provides Tree, Org chart, Radial, alignment and distribution commands. Reset layout restores positions and connector routes from before the first layout. Cross-functional lanes are arranged within their own rows or columns. Smart guides appear automatically while dragging.

Branches and objects

Selecting one node keeps its whole descendant branch prominent while unrelated nodes fade into the background. Use the coloured ± control above the node’s top-right corner to collapse or expand its descendants. Collapsed branches are remembered in browser auto-save and JSON files. The Inspector can lock positions, group shapes, change stacking order, wrap text to a fixed width and copy node or connector formatting with Format painter.

UML and diagram shapes

UML mode includes flowchart, UML, data-flow, ERD, BPMN, sequence-diagram and swimlane shapes, plus UML and message connectors. Click a shape to add it or drag it onto the canvas.

Connectors

Elbow connectors can route around shapes. Add as many bend points as needed, then drag their numbered handles on the canvas; Clear points returns to automatic routing. Format painter copies a connector’s line type, corners, colour, thickness, dash, markers and avoidance setting without changing its label, endpoints or route.

Save and export

Maps auto-save in this browser. File provides JSON, PNG, SVG and a one-click Download all command that saves JSON, PNG and PDF. Print / Save as PDF retains web links.
